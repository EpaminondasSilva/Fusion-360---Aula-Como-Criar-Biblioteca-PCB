# Tutorial & Apresentação Interativa: Biblioteca PCB e 3D (STL/STEP) no Fusion 360

Site e apresentação interativa passo a passo ensinando como:
1. Baixar Símbolo, Footprint (`.lbr`) e Modelo 3D (`.stl` / `.step`) gratuitos (SnapMagic, Ultra Librarian, SamacSys).
2. Criar uma nova Biblioteca Eletrônica no **Autodesk Fusion 360** e importar o arquivo `.lbr`.
3. Vincular o modelo 3D (`.STL` ou `.STEP`) ao Footprint, alinhar no plano `Z = 0` e converter malha STL em sólido (`Convert Mesh`).
4. Conectar os pinos do Símbolo aos Pads do Footprint (`Connect`).
5. Ativar a biblioteca no `Library Manager` (`In Use`) e enviar a placa para o `3D PCB`.
