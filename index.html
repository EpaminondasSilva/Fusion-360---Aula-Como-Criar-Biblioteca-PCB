🆘 Guia Rápido Assíncrono — Telas e Posições Exatas

Chegou atrasado ou perdeu onde clicar? Veja abaixo o resumo de cada etapa e toque em "Abrir Tela" para ver a janela correspondente do Fusion 360:

1. Criar a Nova Biblioteca
📍 Canto Superior Esquerdo (Ícone de Folha 📄)

EN: File → New Electronics Library
PT: Arquivo → Nova biblioteca de eletrônicos → Ctrl + S.

2. Importar Símbolo + Footprint (.LBR)
📍 1ª Coluna da Esquerda (Components / Componentes)

EN: Botão Import → Open from local disk
PT: Botão Importar → Abrir do disco local (escolha o .lbr).

3. Abrir Editor 3D do Footprint
📍 3ª Coluna da Biblioteca (Footprints)

Clique com o Botão Direito no Footprint:
EN: Create new 3D Package from footprint
PT: Criar novo pacote 3D a partir do footprint

4. Inserir e Converter Arquivo .STL
📍 Barra Superior (Menu Insert e Aba Mesh)

1) Insert → Insert Mesh (Inserir malha) → Millimeter → Move to Ground.
2) Aba Mesh (Malha) → Modify → Convert Mesh.
3) Botão verde Finish / Concluir (Topo Direito).

5. Conectar Pinos (Symbol ↔ Footprint)
📍 1ª Coluna (Duplo Clique) → Rodapé Direito

Duplo clique no Componente → Tabela Variants (Variantes) → Botão Connect (Conectar) → Salvar (Ctrl + S).

6. Ativar no Projeto e Enviar para 3D
📍 Barra Superior do Esquemático

1) Library → Open Library Manager → Ative In Use (Em uso).
2) Place Component → Switch to PCB → Push to 3D PCB.
